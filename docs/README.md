# Gacela Router documentation

Gacela Router is a minimalistic HTTP router. Start with [Getting started](getting-started.md), then read the page for what you need.

- [Getting started](getting-started.md): install, a minimal app, how to run it
- [Routing](routing.md): HTTP methods, controllers, path patterns, parameters, groups
- [Responses](responses.md): strings, arrays, `Stringable`, `Response` and `JsonResponse`
- [Named routes and URLs](url-generation.md): naming a route and building its URL
- [The request](request.md): reading query and body data, and injecting `Request`
- [Middleware](middleware.md): global, per-route and grouped middleware
- [Error handling](error-handling.md): mapping exceptions to handlers
- [Use it within Gacela](gacela-integration.md): the `RouterGacelaConfig` adapter and plugins

Requires PHP `>=8.3`.
